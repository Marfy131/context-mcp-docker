## Prerequisites

- Node.js 18+
- An embedding provider API key — OpenAI (used below), or Gemini / Cohere / Voyage / local Ollama (see [Configuration](/docs/configuration))
- Pinecone account + API key

## Setup

<Steps>

<Step>

### Initialize

```bash
npx contextmcp init
cd your-project-name
```

</Step>

<Step>

### Configure

```bash
cp config.example.yaml config.yaml
cp .env.example .env
```

Edit `.env` with your keys:

```bash
OPENAI_API_KEY=sk-...
PINECONE_API_KEY=...
GITHUB_TOKEN=ghp_...  # Optional: for private repos
```

Edit `config.yaml` to point to your docs:

```yaml
vectordb:
  provider: pinecone
  indexName: my-docs
  pinecone:
    cloud: aws
    region: us-east-1

embeddings:
  provider: openai
  model: text-embedding-3-large
  dimensions: 3072

sources:
  - name: docs
    type: github
    repository: your-org/your-repo
    path: docs/
    parser: mdx
```

See [Configuration](/docs/configuration) for all options.

</Step>

<Step>

### Index

```bash
npm run reindex
```

</Step>

<Step>

### Deploy

Deploy as a Cloudflare Worker (managed edge) or self-host with Docker —
both serve the same `/mcp` and `/search` endpoints from the same Pinecone index.

<Tabs items={['Cloudflare Workers', 'Docker (self-hosted)']}>

<Tab value="Cloudflare Workers">

```bash
cd cloudflare-worker
wrangler secret put OPENAI_API_KEY
wrangler secret put PINECONE_API_KEY
npm run deploy
```

Your server is live at `https://contextmcp.your-subdomain.workers.dev`

</Tab>

<Tab value="Docker (self-hosted)">

```bash
cd server
cp .env.example .env   # set PINECONE_API_KEY, PINECONE_INDEX_NAME + provider key
docker build -t contextmcp-server .
docker run --rm -p 8787:8787 --env-file .env contextmcp-server
```

```bash
curl http://localhost:8787/health   # {"status":"ok", ...}
```

Or one command — `docker compose up --build -d` (reads `server/.env` automatically).

See [Deployment](/docs/deployment) for details.

</Tab>

</Tabs>

See [Deployment](/docs/deployment) for GitHub Actions auto-reindex.

</Step>

<Step>

### Connect Your Editor

<Tabs items={['Cursor', 'Windsurf', 'Claude Desktop']}>

<Tab value="Cursor">

Add to `~/.cursor/mcp.json`:

```json
{
  "mcpServers": {
    "my-docs": {
      "url": "https://your-worker.workers.dev/mcp"
    }
  }
}
```

</Tab>

<Tab value="Windsurf">

Add to `~/.codeium/windsurf/mcp_config.json`:

```json
{
  "mcpServers": {
    "my-docs": {
      "serverUrl": "https://your-worker.workers.dev/mcp"
    }
  }
}
```

</Tab>

<Tab value="Claude Desktop">

Add to `~/Library/Application Support/Claude/claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "my-docs": {
      "command": "npx",
      "args": ["-y", "mcp-remote@latest", "https://your-worker.workers.dev/mcp"]
    }
  }
}
```

</Tab>

</Tabs>

Restart your editor. Done!

</Step>

</Steps>

## Test It

```bash
# Health check
curl https://your-worker.workers.dev/health

# Search
curl "https://your-worker.workers.dev/search?query=authentication"
```
